# О!кно — трек «О!дин шаг до идеального отеля» (Ostrovok Hackathon 2026)

Сервис, который знает об отелях Сочи то, чего нет в карточке — вид из окна по этажам, путь до пляжа с подъёмом, шум по сторонам здания, что рядом ночью, — честно показывает, откуда это известно, и помогает выбрать отель без разочарований.

> 🚧 В разработке. Финальный README (видео, быстрый старт, сидирование, маршруты) — по шаблону организаторов к сдаче 29.10.

## Быстрый старт
```bash
git clone https://github.com/ostrovok-hackathon-2026/vot-takaya-vot-komanda-sobachka.git
cd vot-takaya-vot-komanda-sobachka
cp .env.example .env   # необязательно: без ключа LLM всё работает
docker compose up --build
# открыть http://localhost:8080
```
Сборка с нуля — около минуты (плюс скачивание базовых образов node и python). Образ ~210 МБ, один контейнер, `/health` → `{"status":"ok"}`.

## Что умеет (на 25.10)
- **Поиск без фильтров:** «✨ Опишите, какой отель нужен» → линзы «Вид на море», «Закат из окна», «Рядом пляж», «С пляжа не в гору» и 36 фильтров «что рядом»; у каждого отеля — почему подходит и в чём нет.
- **О!кно:** вид из окна по сторонам и этажам для 194 отелей, закат над морем по месяцам.
- **Частые вопросы в карточке:** ответ отеля → посчитанное системой → общее для Сочи/края; нет ответа — «Этого мы пока не знаем :(» и «Спросить у отеля».
- **Экстранет отельера** (`/#extranet/<id отеля>`, кнопка «Для отелей»): вопросы гостей со счётчиком спроса, ответ своими словами → «как мы поняли» → гость сразу видит ответ; «Верно / Исправить» для того, что система узнала сама.
- Без ключа LLM работает всё: разбор фраз и ответов — правила и морфология (pymorphy3).

## Откуда данные
| Что | Источник | Как получено |
|---|---|---|
| Отели Сочи (718) | OpenStreetMap | `features/hotels/pipeline/build_hotels.py`; цена, рейтинг, отзывы — мок |
| Вид из окна, закат | Copernicus DEM GLO-30 + дома OSM | `features/okno/pipeline/` — профиль горизонта по сторонам и этажам |
| Путь до пляжа, «что рядом» | OSM (пешеходная сеть, 12 тыс. мест) + DEM | `features/beach_route/pipeline/`, `features/nearby/pipeline/` |
| Вода в море по месяцам | Open-Meteo Marine, 2023–2025 | `features/knowledge/pipeline/build_knowledge.py` |
| Галька или песок | OSM `natural=beach` + `surface` | там же |
| Туристический налог | Налоговый кодекс РФ, гл. 33.1 | там же, с ссылками |
| Ответы отелей | **имитация для демо** (17 ответов 7 отелей, `features/hotelier/demo_answers.json`) | проходят тот же разбор, что и настоящие; в интерфейсе — «Так ответил отель (демо)» |

## Метрики
- Разбор свободного ответа отельера по полям (без LLM): `python features/hotelier/pipeline/eval_parse.py` — 55/55 полей на 25 размеченных ответах. Правила подбирались на этой же выборке, поэтому на новых ответах точность будет ниже; ошибку разбора ловит отельер на шаге «как мы поняли».
