# data — демо-данные

- `raw/` — скачанные открытые данные (OSM, DEM). В git не коммитятся, воспроизводятся скриптами `features/data_sources/pipeline/`.
- `derived/` — результаты офлайн-расчётов, которые нужны приложению при запуске (коммитим, если маленькие).
Как получены данные — описывается в README фичи `data_sources` (требование организаторов).
