# Фичи

Одна фича = одна папка (договорённость команды, 24.10). Внутри каждой:
- `README.md` — зачем, что делает, API, зависимости, критерии готовности, статус
- `backend/` — код API и логики фичи (роутер подключается в `app/`)
- `pipeline/` — офлайн-расчёты фичи (запускаются заранее, результат в `data/`)
- `frontend/` — компоненты интерфейса фичи

Общий код (гео-утилиты, LLM-клиент, подключение к БД, конфиг) — в `core/`. Хранилище фактов — фича `facts`, через её интерфейс пишут и читают все остальные фичи.

| Папка | Фича | Приоритет | Задача трека |
|---|---|---|---|
| [`data_sources`](data_sources/README.md) | Сбор открытых данных | P0 | основа для всех задач |

| [`facade`](facade/README.md) | Выбор окна на фасаде | P1 (киллер) | доп.: объяснение |
