# Погода: слой «Осадки» на карте

`features/climate/` · приоритет **P1** · закрывает: примеры трека

## Зачем (что видит пользователь)
В легенде карты переключатель «Дожди в <месяце поездки>»: плавная синяя заливка — где в этом месяце дожди обычно чаще. У моря светлее, в горах (Красная Поляна) синее. Это **норма**, не прогноз.

## Бэкенд / пайплайн → `backend/`, `pipeline/`
Агрегаты Open-Meteo Archive и Marine по месяцам для точки/района.

## Фронт → `frontend/`
Контекст дат, строка в «Твой день».

## API
`GET /api/climate/rain?month=5` → `{month, source, years, per, grid: {lats, lons}, points: [{lat, lon, wet_days, mm, tmax}]}` — `wet_days` и `mm` за неделю (7 дней), `tmax` — средний дневной максимум.

## Готово, когда
- [ ] Данные/расчёт работают на демо-данных Сочи и лежат в `data/` (или воспроизводятся скриптом)
- [ ] Факты пишутся в хранилище с источником, уверенностью и датой (если фича производит факты)
- [ ] API отвечает по контракту выше, есть пример запроса/ответа в этом README
- [ ] Фронт показывает результат в стиле Островка (wiki/design-system.md)
- [ ] Работает без ключа LLM (fallback)

- Статус: **v1 — слой «Осадки»** (28.10, Claude).
  - `pipeline/build_rain.py` → `data/seed/climate_rain.json` (22 КБ, в git): Open-Meteo Historical (ERA5), дневные осадки 2020–2025, сетка 0,2° 4×7 = 28 точек от Лазаревского до Красной Поляны; по месяцам — дней с дождём ≥ 1 мм в неделю, мм в неделю, дневной максимум. Скачивается один раз (~7 мин из-за лимита Open-Meteo); в рантайме сеть не нужна.
