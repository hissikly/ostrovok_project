# Сравнение отелей и «было / стало»

`features/compare/` · приоритет **P1** · закрывает: доп. задача «сравнение отелей»; вопрос эксперта «повлияют ли данные на решение»

## Что видит гость
- **«Сравнить»** у отеля в выдаче и в карточке → корзинка внизу экрана (до 4 отелей) → **«Сравнить N»** → экран `#compare/<id>,<id>…` во всю ширину.
- **Экран сравнения** (макет — `mockups/compare.html`): каждый отель — белая колонка-карточка; строки — сначала включённые в поиске линзы, затем главное (вид на море, тишина, до пляжа, обратно с пляжа, закат в месяц поездки) и «Рядом пешком» (кафе, продукты, аптека 24 ч). Под «Ещё» — то, что знает только отель: завтрак, парковка, с питомцем.
  - Галочка — лучшее в строке (по фактам, не по рейтингу); все одинаковы — галочки нет. Слабое значение — оранжевым.
  - Салатовая рамка — лучший отель под запрос (без запроса — по главному: море, тишина, пляж); в шапке «N из M условий запроса»; внизу колонки — главный минус одной фразой.
  - Клик по значению — «как узнали» теми же словами, что в карточке. Нет данных — «Не знаем» и «Спросить у отеля» (вопрос уходит в Экстранет).
  - **«Мнения расходятся»**: ответ отеля и его сайт говорят разное по одному полю (у Azimut: завтрак «включён» против «за доплату», питомцы «до 10 кг» против «до 15 кг»).
- ~~«Обычный поиск / С О!кном» над выдачей~~ — **убрано из интерфейса 28.10** (решение пользователя: путает, сбросить фильтры можно кнопкой «Сбросить»). Обычная выдача осталась на сервере (`backend/baseline.py`) — на ней считается метрика ниже.

- **«Не нашли, что искали?»** под таблицей (28.10): гость пишет своими словами — «Еду на концерт в Фестивальный, хотим жить в разных спальнях, бюджет ограничен» — и в таблицу дописываются его строки с пометкой «ваше» (убираются крестиком). Не чат: фраза растворяется в строках. Маршрут на карте не рисуем — только значения.
  | Что во фразе | Откуда значение | Строка |
  |---|---|---|
  | место (концертный зал, театр, парк, музей, места «Что посмотреть») | название ищем среди мест OSM (`poi.json`) и `sights.json`; минуты — пешеходный граф, дальше 40 мин — оценка на машине по прямой | «До места «Фестивальный»: 24 мин пешком / ≈ 13 мин на машине» |
  | то, что умеет подбор (море, тишина, «что рядом») | те же функции линз, что в таблице | «До пляжа», «Аптека рядом»… |
  | то, что знает только отель, из базы знаний | `features/knowledge` | «Можно с питомцем?» |
  | про номер и отель своими словами | поиск по текстам сайтов отелей (`features/web_sources`, дословная цитата); нет — «Не знаем · Спросить у отеля» (вопрос свободным текстом уходит в Экстранет) | «Две отдельные спальни: Пишут на сайте — апартамент с двумя спальнями» |
  | «бюджет», «подешевле» | цена из карточки | «Цена за ночь», галочка — дешевле |

  Без ключа LLM фразу разбирают правила (названия мест, регулярки линз, остаток фразы — вопрос к отелю). С ключом модель понимает фразу (какое место, какой вопрос к отелю, важна ли цена) и коротко пересказывает найденную цитату с сайта; значения по-прежнему из карты и сайтов.

## Как устроено
| Файл | Что делает |
|---|---|
| `backend/compare.py` | строки и клетки: значения берутся из тех же функций линз, что и выдача (`features/search/backend/lenses.py`), — сравнение и поиск не расходятся; лучший в строке, «N из M», лучший отель, главный минус |
| `backend/cells.py` | короткое значение + пояснение из факта линзы («С 4-го этажа» / «окна на запад»), ключ сравнения; ответы отеля (база знаний) и сайта отеля — короткими словами, проверка расхождения по полям |
| `backend/custom.py` | «Не нашли, что искали?»: фраза → места (OSM + подборка) и минуты по графу, линзы, база знаний, поиск по сайтам отелей, цена |
| `backend/baseline.py` | обычная выдача и подвохи (линза «нет»); «не знаем» подвохом не считаем |
| `frontend/store.js` | отели в сравнении — в браузере, общие для выдачи, карточки и корзинки |
| `frontend/Compare.jsx`, `CompareTray.jsx`, `CompareButton.jsx` | экран, корзинка, кнопка |
| `pipeline/eval_baseline.py` | метрика (ниже) |

LLM не нужен (с ключом точнее понимает фразу в «Не нашли, что искали?»). Новых данных нет — всё из уже собранных фактов, карты и сайтов отелей.

## API
`POST /api/compare {ids: [2–4 id], lenses: [...], month}` →
```json
{"lenses": ["quiet", "sea_view", "beach_near"], "basis": "query", "month": 5,
 "hotels": [{"id": "w124781631", "name": "Адмирал", "met": 3, "of": 3, "best": true,
             "minus": "Закат над морем бывает, но не в мае", "rating": 9.8, "price_rub": 4600, "...": "..."}],
 "rows": [{"id": "sea_view", "title": "Вид на море", "query": true,
           "cells": [{"state": "match", "value": "С любого этажа", "sub": "окна на запад", "win": true,
                      "source": "computed:horizon", "confidence": 0.65}, "..."]},
          {"id": "near", "title": "Рядом пешком", "cells": [{"items": [{"title": "Кафе", "minutes": 4}, "..."]}]},
          {"id": "breakfast", "extra": true, "cells": [{"value": "Включён", "split": {"hotel": "включён", "site": "за доплату"}}]}]}
```
`POST /api/compare/custom {ids, text, month}` → `{rows: [{id, title, icon, custom: true, cells: [{state, value, sub, key, win, source, confidence, how, ask | ask_text}]}], by: "rules" | "llm", nothing}`.

`POST /api/compare/baseline {lenses, month}` → `{hotels: [{id, rank, our_rank, line_m, traps, unknown, ok}], rank: {id: место}, summary: {top, traps, unknown, kinds}}`.

## Метрика «было / стало»
`python features/compare/pipeline/eval_baseline.py` — 30 запросов (все сочетания 1–3 главных линз + 5 с «что рядом»), май, 27.10:

| Метрика | Значение |
|---|---|
| В первой десятке обычной выдачи есть подвох | 23 из 30 (77%) |
| Подвох уже в топ-3 обычной выдачи | 12 из 30 (40%) |
| Подвохов в первой десятке в среднем | 2,3 |
| Топ-3 отличается от обычной выдачи | 30 из 30 (100%) |

Честно: «топ-3 отличается всегда» завышено — рейтинг в обычной выдаче демо, у многих отелей одинаковый. Содержательная цифра — подвохи: они посчитаны по настоящим фактам (шум по карте, пеший путь с подъёмом, вид из окна).

## Сценарий для видео (15 секунд)
Включить «Тихо ночью», «Вид на море», «Рядом пляж» → «Сравнить» у Pullman, Azimut, «Адмирала» → экран сравнения: у «Адмирала» рамка, у Azimut обратно 27 мин в гору и «мнения расходятся» по завтраку.
