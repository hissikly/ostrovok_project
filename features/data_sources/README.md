## Бэкенд / пайплайн → `backend/`, `pipeline/`
Скрипты скачивания по bbox Сочи: OSM через Overpass (отели, здания, дороги, ж/д, пляжи, POI с opening_hours), Copernicus GLO-30 DEM, Open-Meteo (климат и вода), при возможности OpenCellID, Wikidata. Результат сохраняется в `data/` (маленькие файлы — в git, большие — скачиваются скриптом).

## Готово, когда
- [ ] Данные/расчёт работают на демо-данных Сочи и лежат в `data/` (или воспроизводятся скриптом)
- [ ] Факты пишутся в хранилище с источником, уверенностью и датой (если фича производит факты)
- [ ] API отвечает по контракту выше, есть пример запроса/ответа в этом README
- [ ] Фронт показывает результат в стиле Островка (wiki/design-system.md)
- [ ] Работает без ключа LLM (fallback)

## Статус и заметки
- Статус: в работе. Запросы Overpass — `pipeline/queries/` (`overpass.py <запрос> <выход>`): отели, дома (тайлами, `fetch_buildings.py`), берег и пляжи, **объекты «что рядом» (`poi.overpassql` → `data/raw/osm_poi.json`, 25.10)**.
- Владелец бэкенда: бэкенд · владелец фронта: фронт/продукт
