# Твой день здесь

`features/day/` · приоритет **P1 (киллер)** · закрывает: доп.: объяснение

## Зачем (что видит пользователь)
Видит ленту одного дня поездки из фактов: плюсы и подвохи.

## Бэкенд / пайплайн → `backend/`, `pipeline/`
Сборка ленты по дате и режиму поездки из фактов okno, beach_route, noise, nearby, web_sources (сайт отеля), climate.

## Фронт → `frontend/`
Лента дня в карточке отеля.

## API
`GET /api/hotels/{id}/day?month=5&facade=W&floor=16&mode=kids` — `facade`, `floor`, `mode` необязательны
(без стороны берётся запад или первая посчитанная; этаж — ближайший посчитанный, по умолчанию верхний).

```json
{"hotel_id": "w201474333", "month": 5, "facade": "E", "floor": 16, "mode": null, "built_at": "2026-10-26",
 "scenes": [{"time": "05:19", "icon": "sunset", "title": "Солнце заглянет в окно рано",
             "note": "Рассвет в 04:56. Любите поспать — задёрните плотные шторы с вечера", "good": false,
             "fact_ids": ["w201474333:morning_sun:facade:E"], "facts": [{"source": "computed:horizon+sun", "confidence": 0.65, "…": "…"}]},
            {"time": "10:00", "title": "На пляж 8 минут пешком", "note": "Под горку 29 м, лестницы", "good": true, "…": "…"}]}
```
`skip` — id мест через запятую, куда гость не пойдёт (`coffee`, `beach`, `kids`, `sunset`, `dinner`, `night`); фронт по умолчанию убирает `night` (ночная аптека — «на всякий случай»). У сцен с местом вне отеля есть `stop: {id, name, lat, lon}`.

**Выходы из отеля.** Места вне отеля (кофе, пляж, площадка/аквапарк, смотровая, ужин, ночная аптека) — это выходы из отеля. Если до следующего места меньше часа свободного времени, идём сразу, иначе сначала возвращаемся в отель. В `scenes` добавляются:
- строки пути `{"kind": "walk", "time": "08:22", "title": "8 минут пешком до кофейни", "note": "Небольшой подъём, 18 м", "good": true, "outing": 1, "to": "coffee", "minutes": 8, "arrive": "08:30", "facts": [факт walk_leg]}`; обратная — «9 минут обратно в отель», в `note` — «В отеле в 13:09»;
- у мест, куда идём, — `"visit": {"arrive": "09:09", "until": "13:00", "outing": 1, "n": 2}`, `time` = время прихода, заголовок «как там» («На пляже до обеда», «Кофе в «Surf Coffee»»); справка «13:00 Обратно 9 минут в гору» тогда не нужна — её заменяет строка пути;
- место, куда гость не идёт, остаётся справкой во времени по шаблону («Кофе утром, в 8 минутах пешком»).

Сверху ответа: `"walk": {"outings": 2, "minutes": 31, "meters": 2092, "up_m": 50}`, `"outings": [{"n": 1, "name": "Утром", "depart": "08:22", "back": "13:09", "minutes": 26, "stops": ["coffee", "beach"]}, …]`.

`GET /api/hotels/{id}/day/route?…&skip=night` — то же для карты: `lines` (по линии на выход), `stops` с номерами и `outing`, `outings`, итог `minutes/meters/up_m`. Каждый участок — `core.walk.route` по графу улиц; до места без пешего пути выхода нет (без прямых линий).

Публичная функция для других фич: `from features.day.backend import day` (и `route` из `features.day.backend.day`).

## Зависит от
facts, okno (`data/seed/okno`), beach_route, noise, nearby, web_sources (`web:breakfast|pool|crib`); climate и airport — подхватываются, когда появятся:
- `features.climate.backend.climate(lat, lon, month) -> {"water": число °C, …}` — вода дописывается в сцену пляжа. Не число / `None` / исключение — без воды.
- `features.airport.backend.arrival(hotel) -> {"time": "HH:MM", "title": str, "facts": [факт], "icon"?, "note"?, "good"?}` — первая сцена. Без `time`/`title`/`facts` сцена отбрасывается; исключение при импорте или вызове лента не роняет (проверено заглушками 26.10).

## Статус и заметки
- Статус: **v1, полировка** (26.10, Claude, ветка `feat/day-polish`). v0 — коммит 7ab342a.
- **Сцены** (только при наличии факта, по времени; у мест вне отеля время — из выходов, см. ниже):
  - утро — солнце в окне (подвох, если раньше 08:00) или «не разбудит»;
  - 08:30 завтрак в отеле (`web:breakfast`, цитата с сайта), иначе утренний кофе (`day_cafes.json` ≤10 мин);
  - 10:00 пляж — `beach_route` (под горку, лестницы, переходы, вода из climate); 13:00 обратно — подъём «будто на N-й этаж», с ребёнком — «с коляской тяжело» при подъёме ≥15 м или лестницах;
  - 15:00 бассейн (`web:pool`);
  - с ребёнком: 17:00 площадка ≤10 мин, иначе аквапарк ≤20 мин; 21:00 детская кроватка (`web:crib`, в т.ч. честное «нет»);
  - вечер — закат из «О!кна» для стороны/этажа и месяца («закроет соседний дом», «не видно» + смотровая рядом);
  - 20:30 ужин (`near:restaurant`, иначе `near:cafe`); если в 10 мин нет ни того, ни другого — подвох «Ужинать придётся не за углом»;
  - 23:00 шум ночью по стороне с понятным сравнением («около 35 дБ, как в тихой комнате») + какая сторона тише; 23:30 круглосуточная аптека/магазин.
- **Утро в окне** — офлайн-расчёт `pipeline/morning_sun.py`: по профилям горизонта (`data/derived/okno`, 209 отелей) для 15-го числа месяца — первая минута, когда солнце выше угла закрытия в секторе окна ±80°. Результат — `data/seed/day_morning.json`. Факт `morning_sun` отдаётся внутри сцены (в общее хранилище не регистрируется).
