# guests — кто едет

Кнопка «Гости» в плашке поездки (шапка): взрослые 1–6, дети 0–4 и возраст каждого ребёнка (до года … 17 лет).

- Хранится в браузере (`localStorage` `trip:guests`), без регистрации; хук `useGuests()` общий для всех экранов, изменения расходятся событием `trip:guests`.
- Дети появились — включается интерес «С детьми» (`features/trip_plan`), детей не стало — выключается: «Ваш день здесь» и чемодан собираются с ребёнком.
- Бронь с пожеланием (`features/trip`) сохраняет гостей: `POST /api/bookings {…, "guests": {"adults": 2, "children": [5]}}`; отель в Экстранете видит «2 взрослых, ребёнок 5 лет».
- В «Моей поездке» строка гостей и «С ребёнком» в чемодане — те же гости.

Файлы: `frontend/guests.js` (хук, тексты «2 взрослых, 1 ребёнок»), `frontend/Guests.jsx` (кнопка и окно), `frontend/guests.css`.
Бэкенда своего нет: гости — поле брони в `features/trip`.
