# Отели и базовая карточка

`features/hotels/` · приоритет **P0** · закрывает: ожидаемый результат

## Зачем (что видит пользователь)
Видит реальные отели Сочи на карте и их базовую карточку (звёзды, цена, фото — мок).

## Бэкенд / пайплайн → `backend/`, `pipeline/`
Список отелей из OSM, привязка к контуру здания и фасадам (нормали рёбер), этажность. Мок базовых полей карточки с пометкой «мок».

## Фронт → `frontend/`
Точки отелей на карте, шапка карточки отеля.

## API
`GET /api/hotels`, `GET /api/hotels/{id}`

## Зависит от
data_sources

## Готово, когда
- [ ] Данные/расчёт работают на демо-данных Сочи и лежат в `data/` (или воспроизводятся скриптом)
- [ ] Факты пишутся в хранилище с источником, уверенностью и датой (если фича производит факты)
- [ ] API отвечает по контракту выше, есть пример запроса/ответа в этом README
- [ ] Фронт показывает результат в стиле Островка (wiki/design-system.md)
- [ ] Работает без ключа LLM (fallback)
