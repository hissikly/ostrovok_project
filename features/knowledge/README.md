# База знаний и частые вопросы

`features/knowledge/` · приоритет **P1** · закрывает: задача 3 (источник, уверенность, дата), путь гостя «Откуда мы это знаем», основа для `hotelier`

## Зачем (что видит пользователь)
Гость спрашивает об отеле своими словами («можно с собакой?», «можно ли купаться в мае?») и получает ответ с пометкой, откуда он: «Так ответил отель», «Посчитали сами», «Общее для Сочи». Нет ответа — честное «Этого мы пока не знаем :(» и предложение спросить у отеля.

## Как устроено
- **Уровни места:** `ru` → `ru/krd` → `ru/krd/sochi` → `ru/krd/sochi/<hotel_id>` (районов пока нет). Ответ ищем снизу вверх.
- **Порядок доверия:** ответ отеля → посчитанное системой (факты: этажность OSM, вид из окна, путь до пляжа, «что рядом») → общее знание города/края/страны. Отельер важнее расчёта (решение 25.10).
- **Каталог тем** — `topics.json` (15 тем): вопрос гостю, вопрос отелю (`ask_hotel`, `null` — отель не спрашиваем), поля ответа (choice / number / time / text), синонимы. Новая тема — запись без кода.
- **Понимание вопроса:** `core/textmatch.py` — слова к начальной форме (pymorphy3: «собакой» → «собака», «псом» → «пёс»), синоним совпадает по порядку слов; длинный синоним побеждает короткий. Темы не нашлось — пробуем фильтры «что рядом» («есть ли рядом аптека» → факт `near:pharmacy`).
- **Хранение:** верхние уровни — `data/seed/knowledge.json` (только чтение); ответы отелей — таблица `knowledge` единой базы (`core/db.py`; было SQLite `KNOWLEDGE_DB`) (по умолчанию `data/runtime/knowledge.db`, не в git), новая запись делает старую `superseded` — история сохраняется.

## API
- `GET /api/knowledge/topics` → `[{id, question, icon, fields, synonyms}]`
- `GET /api/hotels/{id}/faq?month=5` → частые вопросы карточки: `[{topic, question, icon, status: answered|unknown, text, level: hotel|computed|city|region|country, note, value, source, confidence, obtained_at, can_ask_hotel}]`, сначала отвеченные
- `POST /api/hotels/{id}/ask {"text": "можно ли купаться в мае и есть ли кроватка", "month": 5}` → `{status: answered|unknown|no_topic, answers: [...], can_ask_hotel}`
  - «купаться в мае» → `swim`: «В мае море около 17°: бодрит, купаются немногие» (Общее для Сочи)
  - «кроватка» → `crib`: «Этого мы пока не знаем :(», `can_ask_hotel: true`
  - «где купить сим-карту» → `no_topic`
- Запись ответа отеля (для `hotelier`): `features.knowledge.backend.write(hotel_path(id), "pets", value, text, "hotelier", 0.9)`
