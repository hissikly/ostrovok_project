# Ручная разметка

## `sea_view.csv` — видно ли море из номеров (25 отелей)
Разметка **слепая**: нашего ответа в таблице нет. Не открывайте эти отели в О!кне, пока не закончите.

Для каждого отеля:
1. Откройте ссылку «Карта» (карточка в Яндекс Картах: фото, панорамы, отзывы) и/или сайт отеля; можно найти отель на Островке.
2. Смотрите **фото из номеров и с балконов**, отзывы («вид на море», «моря не видно»), панораму улицы.
3. В колонку «Видно море» — одно слово:
   - `да` — хотя бы из части номеров море видно нормально;
   - `краешек` — видна только полоска моря между домами или издалека;
   - `нет` — из номеров моря не видно;
   - `?` — понять нельзя (такие строки в подсчёт не идут).
4. «Откуда узнали» — ссылка на фото или отзыв, по которому решили. «Комментарий» — по желанию.

Таблицу можно открыть в Excel / Numbers / Google Таблицах (разделитель `;`); сохранить обратно в CSV с тем же именем.

Подсчёт: `python features/metrics/pipeline/eval_sea_view_labels.py` — точность «видно / не видно» и калибровка уверенности.
