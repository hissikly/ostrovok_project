# Что рядом: ночь, дети, машина, питомцы, связь

`features/nearby/` · приоритет **P1** · закрывает: задача 1

## Зачем (что видит пользователь)
Видит круглосуточные аптеки и магазины, площадки, больницу, парковки, зарядки, площадки для собак, покрытие 4G/5G.

## Бэкенд / пайплайн → `backend/`, `pipeline/`
Поиск POI в пешей доступности по тегам OSM, время пешком; вышки OpenCellID.

## Фронт → `frontend/`
Линзы «ночь», «дети», «машина», «питомец», «связь».

## API
`GET /api/lenses/{lens}`, факты в /facts

## Зависит от
data_sources, hotels, facts

## Готово, когда
- [ ] Данные/расчёт работают на демо-данных Сочи и лежат в `data/` (или воспроизводятся скриптом)
- [ ] Факты пишутся в хранилище с источником, уверенностью и датой (если фича производит факты)
- [ ] API отвечает по контракту выше, есть пример запроса/ответа в этом README
- [ ] Фронт показывает результат в стиле Островка (wiki/design-system.md)
- [ ] Работает без ключа LLM (fallback)

## Статус и заметки
- Статус: **v0 работает** (25.10, Claude). Один инструмент «что рядом» на все фильтры, каталог из 36 фильтров.
- **Новая характеристика = запись в `specs.json`**, без кода: `id`, `title`, `kind`, `group`, `icon`, `osm` (теги OSM), `match_min` (до стольких минут — «рядом»), `partial_min` (до стольких — «можно дойти»), `night` (только `opening_hours=24/7`), `synonyms` (для «опиши» и поиска по фильтрам). Пример: `{"id": "grocery", "title": "Продуктовый рядом", "osm": ["shop=supermarket", "shop=convenience", …], "match_min": 5, "partial_min": 10, "synonyms": ["продукты", "магазин у дома", …]}`. Новый тег OSM — добавить в `features/data_sources/pipeline/queries/poi.overpassql` и перевыгрузить.
- Данные: `poi.overpassql` → `data/raw/osm_poi.json` (12 тыс. объектов, не в git) → `pipeline/export_poi.py` → `data/seed/poi.json` (8 тыс. объектов, 0,6 МБ: координаты, тег, название, круглосуточно, id OSM). Частные бассейны у домов отброшены.
- Расчёт (`backend/tool.py`): при старте сервиса, ~0,4 с на все фильтры, чистый Python (сетка 400 м). Факт `near:<id>` у каждого отеля: `{meters, walk_min, name, kind, lat, lon, count}`, путь — прямая ×1,3 при 75 м/мин; уверенность 0,75. Ничего не нашли в `partial_min` → `{meters: null, within_min}`, уверенность 0,45: «на карте не нашли», а не «нет».
- Факты подключаются к хранилищу через `features.facts.backend.register_provider` — отдельного API нет, всё видно в `/api/hotels/{id}/facts` и в линзах поиска (`near_<id>`).
- Ограничения: OSM знает не все маленькие магазины; часы работы размечены у ~20% объектов (круглосуточно — 247); путь по прямой.
