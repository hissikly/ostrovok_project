# Тишина по сторонам и времени

`features/noise/` · приоритет **P1** · закрывает: задача 1 (гео)

## Зачем (что видит пользователь)
Видит, где шумно в 23:00, и какая сторона отеля тихая.

## Бэкенд / пайплайн → `backend/`, `pipeline/`
Модель шума: дороги по классу, ж/д, бары/клубы с opening_hours, затухание с расстоянием, по фасадам и часам суток.

## Фронт → `frontend/`
Линза шума на карте с ползунком времени.

## API
`GET /api/lenses/noise?hour=23`, факты в /facts

## Зависит от
data_sources, hotels, facts

## Готово, когда
- [ ] Данные/расчёт работают на демо-данных Сочи и лежат в `data/` (или воспроизводятся скриптом)
- [ ] Факты пишутся в хранилище с источником, уверенностью и датой (если фича производит факты)
- [ ] API отвечает по контракту выше, есть пример запроса/ответа в этом README
- [ ] Фронт показывает результат в стиле Островка (wiki/design-system.md)
- [ ] Работает без ключа LLM (fallback)
