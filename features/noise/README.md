# Тишина по сторонам и времени

`features/noise/` · приоритет **P1** · закрывает: задача 1 (гео)

## Зачем (что видит пользователь)
Видит, где шумно в 23:00, и какая сторона отеля тихая.

## Бэкенд / пайплайн → `backend/`, `pipeline/`
Модель шума: дороги по классу, ж/д, бары/клубы с opening_hours, затухание с расстоянием, по фасадам и часам суток.

## Фронт → `frontend/`
Линза шума на карте с ползунком времени.

## API
`GET /api/lenses/noise?hour=23`, факты в /facts

## Зависит от
data_sources, hotels, facts

## Готово, когда
- [ ] Данные/расчёт работают на демо-данных Сочи и лежат в `data/` (или воспроизводятся скриптом)
- [ ] Факты пишутся в хранилище с источником, уверенностью и датой (если фича производит факты)
- [ ] API отвечает по контракту выше, есть пример запроса/ответа в этом README
- [ ] Фронт показывает результат в стиле Островка (wiki/design-system.md)
- [ ] Работает без ключа LLM (fallback)

## Статус и заметки
- Статус: **v0 работает** (25.10, Claude): шум днём и ночью по сторонам здания, линза «Тихо ночью», строка в карточке.
- Данные: `pipeline/extract_sources.py` (pyosmium, выгрузка Geofabrik) → `data/raw/noise_sources.json` (не в git): 2,4 тыс. отрезков крупных дорог (трассы, главные, второстепенные, улицы), 327 участков ж/д, взлётные полосы Адлера (короткие «runway» — вертолётные площадки — отброшены), 144 бара/паба/клуба.
- Расчёт: `pipeline/noise.py` → `data/seed/facts_noise.json` (<1 с). Leq источника на 10 м по классу (трасса 74/67 дБА день/ночь … ж/д 70/66, клуб ночью 75, аэропорт 85 на 100 м), затухание линии −10·lg(d/10), точки −20·lg(d/10), городское −0,02 дБ/м; источник за спиной фасада −12 дБ (экран своего здания). Соседние дома как экран не учтены — оценка скорее «шумнее». Уровни ночью: ≤45 тихо, ≤55 спокойно, ≤62 шумно, выше — очень шумно (ориентир — нормы ВОЗ 40–45 дБ).
- Факт `noise`: `scope` `facade:N|E|S|W` у 209 отелей с контуром (стороны из `data/seed/okno`), `hotel` у остальных; `value {day_db, night_db, level, source: {kind, kind_ru, name, meters}}`; уверенность 0,5 (по сторонам) / 0,4 (у точки отеля). Ночью: тихо 164, спокойно 529, шумно 513, очень шумно 137.
- Поиск: линза `quiet` «Тихо ночью» — лучшая сторона: тихо → подходит, спокойно → частично; «опиши» понимает «тихий», «тишина», «выспаться». Шум внутри номера (стеклопакеты) — вопрос отелю `street_noise` из базы знаний.
- Не сделано: ползунок времени и слой шума на карте, экранирование соседними домами.
- Владелец бэкенда: бэкенд · владелец фронта: фронт/продукт
