# Цена: фильтр и сортировка

`features/price/` · закрывает: удобство поиска (деньги)

Кнопка «Цена» справа от счётчика «N вариантов в Сочи». По клику — карточка:
- **Сначала показывать:** рекомендуем / дешевле / дороже;
- **Цена за ночь:** гистограмма цен всех отелей, ползунок «до N ₽», быстрые суммы по квартилям цен (≈ 4 / 5,5 / 6,5 тыс) и «Любая»;
- «Показать N» — сколько отелей останется.

Когда фильтр включён, кнопка синяя и подписана выбором («до 5,5 тыс ₽ · дешевле»). Работает и с линзами: счётчик «подходят по всем пожеланиям» считается уже с учётом цены.

Цена — мок карточки (`hotels.json → mock.price_rub`): у Островка нет открытого API цен.

## Фронт → `frontend/`
- `PriceFilter.jsx` — кнопка и карточка; `applyPrice(rows, {sort, max})` — для любой выдачи вида `[{h, …}]`.
- Подключено в `features/search/frontend/SearchPanel.jsx` (только список; карта показывает все отели).

Бэкенд не нужен, LLM не нужен.
