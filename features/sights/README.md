# Что посмотреть в городе: подборка мест и «жить рядом»

`features/sights/` · v1 (28.10, Claude) · закрывает: задачи 1–2 трека (характеристика «до места» у каждого отеля, поиск по ней)

## Что видит гость
- В шапке «Сочи» — экран **«Город»** (`#city`): выбор города (заглушка — пока данные только по Большому Сочи, остальные «скоро»), подборка из 12 мест с фото, метками, временем на посещение и фильтром по меткам.
- **«Жить рядом»** у места — место становится фильтром подбора «Рядом: <место>»: отели по времени до него, ближе — выше; на карте место — зелёной точкой. Тот же фильтр — в «Ещё фильтры → Что посмотреть» и через «опиши» («рядом с дендрарием»).
- В карточке отеля — **«Что посмотреть рядом»**: три ближайших места; клик — пеший маршрут на карте с минутами туда/обратно, а если пешком дальше 40 мин — честно «≈ N мин на машине (оценка по прямой)» и обе точки на карте.

## Как считаем
| Что | Как | Уверенность |
|---|---|---|
| Пешком (до 40 мин) | пешеходный граф OSM (`core/walk.py`), «обратная» Дейкстра от места — время именно от отеля до места, по Тоблеру с подъёмами | 0,8 |
| На машине | прямая ×1,3, 40 км/ч + 5 мин на парковку — оценка, не маршрут | 0,5 |

Факт `sight:<id>` у каждого отеля: `{mode: walk|car, minutes, meters, name}`, источник `computed:osm-walk` / `computed:straight-line`, дата, срок годности — как у всех фактов. В списке фактов карточки не показываем — у них свой блок.

Линза `sight_<id>`: пешком ≤ 15 мин — «подходит», ≤ 30 — «частично». Если пешком до места не дойти ни от одного отеля (Ахун, Скайпарк, Роза Хутор) — по машине: «подходит» до +10 мин к ближайшему из наших отелей, «частично» до +25.

## Данные
| Файл | Откуда |
|---|---|
| `sights.json` | список мест — вручную: название, падеж «до чего», описание **своими словами**, метки, время, координаты и id объекта OSM (у Морского вокзала и Розы Хутор — по карте вручную, `osm: null`), синонимы для «опиши», файл фото на Commons |
| `data/seed/sights/<id>.jpg`, `photos.json` | `pipeline/fetch_photos.py` — Wikimedia Commons, только свободные лицензии; автор и лицензия — подписью на фото и в `photos.json` |
| `data/seed/sights_walk.json` (24 КБ) | `pipeline/sight_times.py` — 12 мест × 718 отелей, < 1 с |

Новое место — запись в `sights.json` и два скрипта; кода не нужно.

## API
- `GET /api/sights` → `[{id, name, to, about, tags, duration, lat, lon, walkable, credit, photo, lens}]`
- `GET /api/sights/{id}/photo.jpg`
- `GET /api/hotels/{id}/sights?limit=3` → `[{id, name, to, lat, lon, tags, mode, minutes, meters}]`, сначала пешком, потом на машине
- Подбор: `POST /api/search {"lenses": ["sight_dendrary"]}` — в `reasons` есть `minutes` и `point`

## Ограничения и что дальше
- Машина — оценка по прямой: дорожного графа и пробок нет. Роза Хутор вне нашего графа — только машина.
- Точка места — центр объекта OSM или вход (Агура — касса нацпарка у тропы), не всегда главный вход.
- Дальше (v2): маршрут по нескольким местам и подбор отеля «между ними».
