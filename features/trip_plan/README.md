# trip_plan — день по интересам

Гость один раз отмечает, чем хочет заняться: плавать, культура, тусить, гулять, вкусно поесть, спорт, с детьми, выспаться. Агент-планировщик собирает «Ваш день здесь» у каждого отеля из мест рядом, проверяет их и объясняет каждое решение. Отели в списке идут по тому, какой день из них получится.

Идея — приложение «Иду» (места под настроение), только у нас подбор опирается на факты с источником: место из OpenStreetMap, путь пешком по графу улиц, часы работы.

## Где видно
| Где | Что |
|---|---|
| Шапка, плашка поездки | Кнопка «✦ Чем заняться» рядом с датами и гостями → окно с 8 плитками. Хранится в браузере (`localStorage`), без регистрации. На телефоне — только иконка |
| Список отелей | Строка «✦ Ваш день — всё пешком» (синим текстом, как кнопка интересов; салатовая плашка — только у «О!кна») или «2 из 3 пешком» с подписью «бары — 16 мин»; без фильтров отели отсортированы по этому |
| «Ваш день здесь» (с 28.10 — только в «Моей поездке») | Выбраны интересы — день всегда по ним (переключателей «По интересам» и «С ребёнком» нет: дети — интерес «С детьми»; в окне «Чем хотите заняться?» его нет — включается сам, когда в «Кто едет» есть дети); над сценой — подпись интереса; обед по пути; «Неожиданно» — сюрприз; булавка «оставить в любом варианте»; кнопка «Другой вариант дня»; свёрнутая трасса «Как собрали этот день». Маршрут на карте — тот же, что у ленты дня |

## Как думает агент (`backend/plan.py`)
1. Ставит каждый интерес в своё время: спорт 07:30, плавать 10:00, культура 15:00, дети 16:30, гулять 18:00, поесть 20:00, тусить 22:00 (`backend/interests.py`).
2. Ищет места-кандидаты: фильтры «рядом» (`features/nearby`, путь по графу улиц, до 15 мин; культура — до 20), пляж (`core.walk.to_beach`), бассейн отеля (факт с сайта `web:pool`).
3. Проверяет: открыто ли всё время визита (часы OSM, `backend/hours.py`), есть ли название, не спортивный ли это бассейн; «выспаться» + «тусить» — бар не ближе 5 мин от окон; вода в море холоднее 20° — первым бассейн (если готова фича `climate`).
4. Выбирает: вариант 0 — лучшее (ближе, с известными часами); следующие — другие из 4 лучших в постоянном для отеля порядке. Закреплённое гостем не меняет.
5. Вставляет обед рядом со следующим местом (до 400 м), если утром пляж, а днём — другое место: из кафе сразу идём дальше, не заходя в отель.
6. В нечётных вариантах — сюрприз: смотровая, музей, зоопарк или парк не из интересов, если 16–19 свободно.
7. Пишет трассу: что взял и из скольких, что отсеял и почему, у скольких мест нет часов, что закреплено.

Факты дают только инструменты (OSM, граф улиц, сайт отеля). LLM не нужен — работает без ключа.

Обычная лента дня (`features/day`) остаётся: утро в окне, завтрак, закат, ночью тихо/шумно. Места по интересам заменяют её пляж и бассейн («плавать»), ужин («поесть»), площадку («с детьми»); «с детьми» включает и режим с коляской.

## API
```
GET /api/trip/interests
→ [{"id": "sea", "title": "Плавать", "icon": "waves"}, …]

POST /api/trip/fit {"interests": ["sea", "culture", "party"]}
→ {"w124781622": {"good": 3, "all": 3, "far": [], "unknown": 0, "score": 284}, …}   # все 718 отелей, ~5 мс

GET /api/hotels/w124781622/day?month=5&interests=sea,culture,party&variant=1&pins=culture:way/123
→ обычная лента дня + у сцен по интересам поля interest, interest_title, place, alts, pinned
  + "plan": {"interests": [...], "variant": 1, "variants": 16,
             "trace": [{"kind": "ok|swap|none|pin|surprise|look", "text": "…", "source": "…"}]}

GET /api/hotels/w124781622/day/route?…те же параметры…   → выходы на карту по местам из интересов
```
`variant` — номер варианта (0 — лучший), `pins` — закреплённые места `интерес:osm-id` через запятую.

## Данные
- `data/seed/trip_hours.json` — часы работы 574 мест (бары, кафе, музеи, парки…) из выгрузки OSM: `pipeline/hours.py` (вход `data/raw/osm_poi.json`). В `poi.json` часов нет.
- Остальное — чужие публичные интерфейсы: `features.nearby.backend.places` (добавлен в экспорт), `facts_for`, `core.walk`.

## Как добавить интерес
Запись в `INTERESTS` (`backend/interests.py`): `id, title, icon, slot, stay, specs` (фильтры из `features/nearby/specs.json`), при необходимости `limit`, `named`, тексты «нет рядом». Новый тип места — строка в `KIND` («Музей», «до музея»), новые часы — тег в `KEYS` в `pipeline/hours.py`. Порядок дня — `ORDER`.

## Сценарий для видео (~40 с)
1. Шапка → «Чем заняться» → «Плавать», «Культура», «Тусить» → Готово. Список пересортировался, у отелей «Ваш день — всё пешком».
2. Бронируем «Богородск» → «Моя поездка» → «Ваш день здесь»: пляж → обед в кафе у музея → музей → бар. «На карте» — выходы из отеля.
3. «Другой вариант дня» — другой музей, другой бар, вечером сюрприз «Неожиданно». Закрепляем музей булавкой — следующие варианты его не трогают.
4. «Как собрали этот день» — трасса агента: из скольких мест выбрал, что отсеял и почему.
