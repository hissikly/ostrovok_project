# Сайты отелей (RAG)

`features/web_sources/` · приоритет **P1** · закрывает: задача 1 (LLM + RAG поверх открытых данных), задача 3 (источник и цитата), путь гостя «Частые вопросы»

## Зачем (что видит пользователь)
Многое знает только отель: питомцы, кроватка, парковка, трансфер, время заезда, бассейн. Мы читаем официальный сайт отеля (тег `website` в OSM) и показываем ответ с подписью «С сайта отеля»; по клику — **дословная цитата** и ссылка на страницу. Факт = цитата из источника, а не догадка.

## Как устроено
| Шаг | Файл | Что делает |
|---|---|---|
| 1 | `pipeline/crawl.py` | главная + до 10 страниц того же сайта по ключевым словам (номера, услуги, правила, питомцы, парковка…); robots.txt, 1 запрос/с на сайт, свой User-Agent; у сайтов сетей — только страницы этого отеля → `data/raw/web/<id>.json` (не в git) |
| 2 | `pipeline/index.py` | меню и подвал убираем, текст режем на чанки ~600 символов → `data/seed/web_chunks.json.gz` (0,6 МБ), `data/seed/web_sites.json` (статусы) |
| 3 | `pipeline/extract.py` | 17 тем (`topics.py`): без ключа — правила по предложениям сайта; `--llm` — модель отвечает по найденным чанкам, ответ принимается, **только если цитата дословно есть в тексте**. Слова гостей (отзывы на сайте) и вопросы из FAQ сайта — не факты → `data/seed/facts_web.json` |
| — | `backend/search.py` | BM25 по леммам (`core/textmatch`), индекс лениво на отель — инструмент `web_text` для агента |
| — | `backend/quote.py` | ответ на свободный вопрос с проверкой цитаты (LLM) или лучшее предложение (без ключа) |

Факт: `characteristic: "web:<тема>"`, `source: "web:<домен>"`, `evidence: {url, quote, fetched_at, topic}`, уверенность 0,7 (прямая формулировка) / 0,6 (косвенная, напр. «Люкс с балконом» → балкон в части номеров) / 0,5 (длинная фраза), срок годности 90 дней.

Перезапуск: `crawl.py --retry` (только не ответившие) → `index.py` → `extract.py [--llm]`. Ключ — в `.env` (`LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`), ответы модели кэшируются в `data/raw/web/_llm_cache.json`.

## Где в интерфейсе
- **Частые вопросы** (`features/knowledge`): уровень `web` «С сайта отеля» — после ответа отеля и расчёта, раньше общего знания по Сочи. Темы с ответом на сайте добавляются в список карточки. Вопрос не из каталога («есть ли бассейн», «есть ли тренажёрный зал») → тема сайта или цитата из найденного куска; нет — как раньше «не знаем, спросить у отеля».
- **Что важно знать** (`features/facts`): одна строка «На сайте отеля пишут» — бассейн, свой пляж, кухня, Wi-Fi, лифт; по клику цитата.
- `sea_view` («все номера с видом на море») и `beach_claim` («5 минут до моря») не показываем — это обещания отеля для сверки с расчётом (`features/conflicts`).

## API
- `GET /api/hotels/{id}/web` → `{website, status, pages, fetched_at, facts: [...]}`
- `GET /api/hotels/{id}/web/search?q=тренажерный зал&k=4` → `[{text, url, title, fetched_at, score, matched}]` (инструмент `web_text`)
- `GET /api/web/stats` → сколько сайтов ответило, фактов, тем
- Публичный интерфейс: `from features.web_sources.backend import answer, ask, search, topics_for, web_facts`

Пример: `POST /api/hotels/w207579132/ask {"text": "можно с собакой?"}` → «Можно с питомцем», `level: web`, цитата «Обратите внимание: отель Omega Sirius принимает гостей с домашними питомцами.», ссылка siriushotels.ru/omega/. Azimut `w51764141`: «Можно с питомцем до 15 кг, доплата 1500 ₽» (виден, если нет демо-ответа отельера — он главнее).

## Статус и заметки
- Статус: **v0 работает** (26.10, Claude): правила, без ключа.
- Обход 26.10: из **236** сайтов ответили **72** (31%). Остальные: 74 обрывают TLS, 67 не резолвятся/недоступны, 17 — 4xx/5xx/пусто. Обход шёл с зарубежного IP (VPN) — многие российские сайты такой трафик режут: **перезапустить `crawl.py --retry` без VPN**.
- Факты: **321 у 61 отеля, 16 тем** (балкон 39, Wi-Fi 34, бассейн 33, кондиционер 28, вид на море 27, трансфер 23, кухня 22, завтрак 21, питомцы 20, «до моря» 19, парковка 17, кроватка 12, заезд/выезд 12, лифт 6, свой пляж 5, тишина 3).
- Ограничения правил: подпись к иконке («Можно с животными») беднее фразы; отзывы, вклеенные в главную, отсекаются эвристикой (прошедшее время, смайлы) — не идеально; «курить» ≠ «курение» в поиске (леммы разные). С ключом LLM — точнее.
- Отзывы агрегаторов не скрапим (условия сайтов, вопрос организаторам — Q&A 27.10).
- Не сделано: эмбеддинги (BM25 хватает на сайт одного отеля).
