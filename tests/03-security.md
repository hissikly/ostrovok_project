## Осознанно оставлено (демо)

- **Экстранет и `/api/*` без входа.** Любой, кто открыл сервис, может ответить за отель или добавить характеристику.
  Для локального демо жюри это нормально. В продакшене нужен вход отельера (SSO Островка) и роль администратора для «Научить О!кно».
- Нет ограничения частоты запросов к LLM-эндпоинтам. Длина текста уже ограничена. Для публичного развёртывания — rate limit на прокси.
- Подложка карты, шрифт и LLM — внешние сервисы. В них уходят только координаты области карты и текст запроса гостя, без персональных данных.
