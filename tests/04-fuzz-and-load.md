# Фаззинг и нагрузка

Стенд: Docker (app + PostgreSQL 16), основной LLM недоступен, работает запасной.

## Плохие входы — `tests/scripts/fuzz_inputs.py`

358 запросов: несуществующие id и id-атаки (`../../etc/passwd`, `' OR 1=1 --`, `<script>`, 5000 символов, эмодзи), мусор в параметрах (`floor=abc`, `month=13`, `lat=nan`),
мусорные тела (пустое, битый JSON, 100 КБ текста, NUL-символ, `{{7*7}}`, `%s%n`), обход путей к файлам. Ищем 500 и утечку исходников.

| Прогон | 5xx | Утечка файлов |
|---|---|---|
| Первый, после переезда на PostgreSQL | **2** — NUL-символ в тексте вопроса отелю и в ответе на конфликт (Postgres не хранит NUL) | 0 |
| После исправления в `core/db.py` | **0** | 0 |

## Нагрузка — `tests/scripts/load_all_endpoints.py`

Все GET-эндпоинты по всем 696 отелям + поиск, «Опишите», сравнение, вопросы. 32 потока.

| Метрика | Значение |
|---|---|
| Запросов | 12 032 |
| Время | 33.7 с, **357 запросов/с** |
| Коды | 200 — 11 988; 404 — 39; 422 — 5; **5xx — 0** |
| Задержка (200) | p50 7 мс, p95 528 мс, max 3.0 с |

404 — у 39 отелей нет маршрута к пляжу (штатный ответ), 422 — `/api/climate/rain` без обязательного `month`.
