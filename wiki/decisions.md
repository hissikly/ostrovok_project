# Решения команды

| Дата | Решение | Почему | Статус |
|---|---|---|---|
| 2026-10-24 | Глубоко прорабатываем **один регион**, а не весь мир | Заметки команды; рекомендация организаторов в тексте трека | принято |
| 2026-10-24 | Учитываем **рельеф** (вид, пешая доступность с перепадом высот) | Идея команды из заметок; прямо совпадает с примерами трека | принято |
| 2026-10-24 | **Не чат-бот.** Главный интерфейс — визуальный (3D-карта, линзы, «Окно»), текстовый ввод — вспомогательный («✨ опиши» настраивает интерфейс, а не отвечает сообщениями) | Решение пользователя: чат «примитивно и не юзер-френдли» | принято |
| 2026-10-24 | Покрываем **все примеры из задания** + киллер-фичи | Решение пользователя | принято |

| 2026-10-24 | Концепция v2 «О!кно» в целом одобрена | «идея мне очень нравится в целом» | принято |
| 2026-10-24 | Регион — **Большой Сочи** (Центр, Хоста, Адлер) | Рельеф, море на западе (закаты), ж/д и аэропорт, аудитория Островка | предложено, не подтверждено |
| 2026-10-24 | LLM никогда не создаёт факты об отелях; всё работает и без ключа (fallback) | Требование «не угадывать» + неясность с ключами для жюри | предложено |
| 2026-10-24 | Стек: Python/FastAPI/SQLite + React/MapLibre, один контейнер, тяжёлые расчёты офлайн | Простой запуск ≤10 мин | предложено |
| 2026-10-24 | Параллельный агент в Cursor («ИИ-завод») — **пока не используем** | Решение пользователя после обсуждения схемы (git + карточки задач + ревью) | отложено |
| 2026-10-24 | Добавляем в продукт ответ на 3 вопроса эксперта: «главное — первым» (релевантность), калибровка уверенности (доверие), режим «было / стало» (влияние на решение) | Уточнение Ilia Marashli 24.10 18:31; одобрено пользователем | принято |
| 2026-10-24 | **Одна фича = одна папка** `features/<фича>/{backend,pipeline,frontend}`; общее в `core/` | Просьба бэкендера | принято |
| 2026-10-24 | Работаем вдвоём: фронт/продукт (+Claude) и бэкенд (+его агент). Общие правила — `AGENTS.md`; wiki ведёт Claude, бэкенд пишет в `wiki/inbox.md` | Решение пользователя | принято |
| 2026-10-25 | Закреплённых зон нет: оба участника работают над всем; единственное правило — новая фича в своей папке `features/<фича>/` | Уточнение пользователя | принято |
| 2026-10-25 | Расчёт «О!кна» для всех ~209 отелей с контуром (докачка домов тайлами + батч) ведёт **отдельный агент «О!кна»**; основная сессия идёт дальше по пути гостя, следит за обновлениями через wiki/inbox | Решение пользователя | принято |
| 2026-10-25 | Поиск: линза без нужного факта отвечает **«не знаем»**, отель не выкидываем, а показываем ниже с пометкой «про это пока не знаем» (общую подпись «знаем для N из 718» пользователь убрал 25.10) | Честность важнее красивой выдачи; эксперт: «можно ли доверять» — часть задания | принято |
| 2026-10-25 | «До пляжа» v0 — по прямой до `natural=beach` ×1,3 (уверенность 0,55–0,6); подъём с пляжа = высота отеля над морем. Настоящий маршрут с рельефом — следующий шаг `beach_route` | Нужен был гео-факт для всех 718 отелей сразу, чтобы поиск не был пустым | принято |
| 2026-10-25 | «Что рядом» — **один инструмент** по объектам OSM (ближайший объект нужного типа, метры, минуты пешком, часы работы); новая характеристика = описание (типы OSM + порог), а не новый код | Закрывает задачу 4 (расширяемость) и десятки пожеланий гостя разом; одобрено пользователем | принято |
| 2026-10-25 | Каталог из многих готовых фильтров «рядом» считаем заранее; на экране — 4 основные линзы, остальное в свёрнутом «Ещё» с поиском; «опиши» находит фильтры по синонимам («магазин у дома» → «Продуктовый рядом»), LLM — только если есть ключ | Пользователь: не засорять экран; без ключа всё должно работать | принято |
| 2026-10-25 | Пешие маршруты — **свой граф из OSM** (`core/walk.py`), без внешних сервисов: время по Тоблеру туда и обратно, подъём по карте высот; им пользуются путь до пляжа, «что рядом» и маршрут до места по клику | Работает у жюри без интернета и ключей; одним графом закрыты beach_route и nearby; одобрено пользователем | принято |
| 2026-10-25 | Пешеходную сеть берём из выгрузки Geofabrik `south-fed-district` (316 МБ, не в git), а не из Overpass | Overpass перегружен: за 40 мин скачалось 8 тайлов из 35; выгрузка — 2 мин + 18 с вырезки; одобрено пользователем | принято |
