# Дизайн-система: делаем «как Островок»

Публичного брендбука нет. Токены ниже **извлечены из CSS ostrovok.ru** (24.10, 261 переменная — полный список в `raw/brand/ostrovok-css-tokens.txt`). Айдентика — по публикациям о ребрендинге 2024 (агентство The Clients) и слайдам хакатона.

**Акцент для промо/героев** (со слайдов хакатона, не из CSS): светло-салатовый фон с мягким переходом в белый (~`#E6F5D0` → `#F4FAEC`) + крупные заголовки цвета бренда. Ребрендинг 2024: «зелёные и синие круглые объекты» в фотостиле.

## Форма
- Радиусы: `4 / 6 / 8 / 12 / 20 px` (`--t-radius-2xs…lg`). Кнопки и поля — **12 px**. Карточки — 12–20 px.
- Отступы: `2 / 4 / 8 / 12 / 16 / 20 / 24 px`.
- Кегли: `12 / 14 / 16 / 20 px` в интерфейсе; заголовки героев — крупные, жирные.
- Высота шапки 48 px, шапка белая, логотип синий.
- Тени почти не используются — плоские карточки с бордером `#E5E5E5`.

## Айдентика
- Логотип: «Островок» с **восклицательным знаком**; короткий знак — **«О!»**. Вся линейка треков хакатона названа «О!дин …».
- Главный графический элемент — **буква «О»**: растянутая «О» в лайнах, паттерны из повторённой «О», круглые объекты в фото.
- Для нас это подарок: «О!кно» — окно в форме «О»; круглые линзы; круглый «отпечаток отеля».

## Шрифт
Фирменный шрифт с сайта извлечь не удалось (CDN со стилями не отвечал). Слайды — жирный геометрический гротеск с широкой «О». **Замена: `Manrope`** (Google Fonts, есть кириллица, геометрия близкая): 800 — заголовки, 600 — акценты, 400–500 — текст. Если найдём настоящий — заменить.

## Иконки
Иконки сайта — линейные SVG 20–24 px, без заливки, скруглённые концы. Замена: **Tabler Icons outline** (stroke 1.75–2) или Lucide. Цвет — `#2D3137` / `#868686`, активные — бренд-синий.

## Правила для наших экранов
- Белый фон, синий — только для действий и активного состояния; одна primary-кнопка на экран.
- Наши «смысловые» цвета характеристик (море, закат, тишина, усилие) держим приглушёнными, чтобы не спорить с брендом: море `#3D8BFD`→`#BFD8FF`, закат `#FF8A3D`, тишина `#53AF24`, шум `#CE2121`, рельеф `#B9B4A7`.

## Как выглядит приложение Островка (скрины 25.10, `raw/brand/app-screens-2026-10-25/`)
- **Белые карточки с большим скруглением (~24 px) на светло-сером фоне** — без рамок и теней; экран собран из таких блоков.
- **Крупные жирные заголовки** (~26–30 px), плотный тёмный текст, много воздуха.
- **Рейтинг — зелёная плашка** с белой цифрой («8,8 Отлично», «9,1»).
- **Строки с иконками**: 📍 адрес, «30,2 км от центра», «1,7 км от пляжа» — короткие факты одной строкой.
- **Серые таблетки-чипы с иконкой**: «До 4 гостей», «1 комната», «21 кв.м».
- **Салатовый градиент** (промо GURU, `~#D6F7B8 → #B3EF8C`) с синим акцентом — «свежий» элемент, используем для одного главного вывода на экране.
- «Лучшая цена» — светло-зелёная плашка с зелёным текстом; ссылки и вторичные кнопки — синий текст на `#E3EBFD`; главная кнопка — синяя, скругление 12–16 px.

## Правила подачи (решения 25.10)
- Никакого техтекста в интерфейсе (названия датасетов, «уверенность 65%» и т.п.) — только в «как мы это узнали» по клику.
- Никаких легенд: смысл цвета объясняет само предложение.
- Уверенность — словами: «точно» (≥0.8), «по расчёту» (0.6–0.8), «примерно» (<0.6).
- **Без разделителей «·»** между словами (пользователь называет это «нейрослопом»): группы — отдельными элементами, сегментами с иконками или строками.
- Факты по сторонам здания сводим в один блок строк «Окна на запад — с любого этажа»; было: в одну строку («Вид на море: запад — с 1 этажа, север — с 8-го, восток — нет»).
